# Les Pattes Heureuses

Site vitrine statique pour un cabinet vétérinaire fictif, avec prise de rendez-vous, contact, tarifs,
FAQ, galerie, équipe et avis clients.

## Ouvrir le site

Ouvrez `index.html` dans un navigateur.

## Fichiers principaux

- `index.html` : structure de la page et contenus.
- `styles.css` : direction artistique, responsive, composants.
- `script.js` : menu mobile, date minimale de rendez-vous, validation des formulaires.
- `assets/` : logo SVG et images générées pour le hero/la galerie.
